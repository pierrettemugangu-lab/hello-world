Git & GitHub Commands Reference Guide

1. Repository Initialization & Configuration

  • git init - Initializes a new local Git repository in the current folder.
  • git branch -M main - Renames the default local branch to main.

2. Local Workflow (Tracking & Committing)

  • git status - Displays the current state of modified, staged, or untracked files.
  • git diff - Shows unstaged line-by-line changes made to files.
  • git add [filename] - Stages a specific file for the next commit.
  • git add . - Stages all modified, deleted, and newly created files at once.
  • git commit -m "your message" - Saves a snapshot of staged changes with a descriptive message.
  • git log - Displays the complete commit history.
  • git log --oneline - Displays a condensed, single-line commit history.

3. Remote Repository Connection

  • git remote add origin [URL] - Links your local repository to a remote GitHub repository.
  • git remote set-url origin [URL] - Updates or corrects the remote repository URL.
  • git remote -v - Lists all remote connections associated with your local repository.

4. Pushing & Pulling Changes

  • git push -u origin main - Uploads local commits to GitHub for the first time and sets default branch tracking.
  • git push - Uploads local commits to the default remote branch after initial setup.
  • git pull origin main - Fetches and merges changes from the remote repository to your local folder.

5. Cloning & Forking

  • git clone [URL] - Downloads an entire remote repository to your local machine.
  • Forking: Created via the GitHub interface by clicking Fork, then downloaded locally using git clone [FORKED_URL].
