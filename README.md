# Git & GitHub Practice Assignment

This repository contains a reference guide for essential Git commands and GitHub workflows, created as part of the practice exercise.

## Project Overview
The goal of this assignment is to build strong muscle memory for daily Git commands and master the workflow between local and remote repositories.

## Assessment Objectives Covered
- Connected a local repository to a remote repository on GitHub
- Staged, committed, and pushed local changes to a remote repository
- Pulled remote updates to the local machine
- Cloned a repository from GitHub
- Forked a public project on GitHub

## Summary of Git Commands Used

### 1. Repository Setup & Remote Connection
* git init - Initialized the local repository.
* git branch -M main - Set the default branch to main.
* git remote set-url origin [URL] - Linked local repository to GitHub.

### 2. Daily Local Workflow
* git status - Checked the status of files.
* git diff - Reviewed line-by-line changes.
* git add . - Staged all modified files.
* git commit -m "message" - Saved snapshots of changes.
* git log --oneline - Viewed condensed commit history.

### 3. Remote Operations
* git push -u origin main - Uploaded local commits to GitHub.
* git pull origin main - Synchronized remote changes locally.
* git clone [URL] - Downloaded a repository copy locally.
